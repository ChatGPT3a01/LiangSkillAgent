# 亮言 Skill Vibe Coding AI Agent

> 把你電腦裡所有的 AI 技能（SKILL）整理成一張表，
> 再讓 AI Agent 幫你把「亂亂的想法」整理成可以直接貼給 AI 的任務提示詞。

<div align="center">

### ⬇ [下載安裝程式（Windows）](https://github.com/ChatGPT3a01/LiangSkillAgent/releases/latest/download/LiangSkillAgent-Setup.exe)

最新版本與更新紀錄：[Releases](https://github.com/ChatGPT3a01/LiangSkillAgent/releases)

</div>

## ✨ 可以做什麼

| 功能 | 說明 |
|---|---|
| 📋 技能總表 | 自動找出電腦裡 Claude Code、Codex、Gemini 等的技能，列出功能、工作流、示範提示詞與資料夾位置 |
| 📦 整理任務提示詞（AI Agent） | 想做什麼直接打（口語、零散都可以），AI 會整理需求、替你做決定、挑出要用的技能，產出一整份可以複製貼到 ChatGPT／Claude／Gemini 的任務包 |
| 🔎 推薦技能 | 問「要做某件事該用哪些技能」，AI 依工作流排出使用順序 |
| 🤖 多種 AI 可選 | Claude Code、Codex、Gemini CLI、Antigravity、OpenCode，或免費的 Ollama 地端模型 |
| ⚙️ 一鍵安裝與設定 | 網頁裡就能一鍵安裝／登入 AI、下載地端模型、調整字體大小 |
| ❓ 使用教學 | 第一次打開自動帶你一步一步看過所有功能 |

## 💻 系統需求

- Windows 10／11（64 位元）
- **不用另外安裝 Python**，安裝程式已經內附
- 需要**課程密碼**才能安裝與啟用（僅提供給阿亮老師課程學員）
- 想用雲端 AI 的話，需要該服務的帳號（例如 Claude Pro、ChatGPT Plus、Google 帳號）；地端模型免費

## 🚀 安裝步驟

1. 點上方「**下載安裝程式**」，下載 `LiangSkillAgent-Setup.exe`。
2. 點兩下執行。如果出現「**Windows 已保護您的電腦**」，按「**其他資訊**」→「**仍要執行**」（這是因為安裝程式沒有購買數位簽章，不是病毒）。
3. 輸入**課程密碼**（請向阿亮老師索取），再照安裝精靈按「下一步」：
   - 選擇技能資料夾（不確定就用預設值）
   - 勾選「在桌面建立圖示」
4. 安裝完成，勾選「立即開啟」。第一次開啟時再輸入一次**課程密碼**啟用，之後這台電腦就不用再輸入。
5. 之後點兩下桌面上的「**亮**」圖示就能開啟。想放在**工作列**：在圖示上按右鍵 →「釘選到工作列」（Windows 11 請先按「顯示更多選項」）。

## 🔄 更新

在「⚙️ 設定 → 版本、更新與安裝程式」按「**檢查是否有新版本**」。有新版本時下載新的安裝程式，點兩下安裝即可，**會自動覆蓋舊版，你的設定都會保留**。

## 🗑 解除安裝

Windows「設定 → 應用程式 → 已安裝的應用程式」，找到「亮言 Skill Vibe Coding AI Agent」→ 解除安裝。

## 🔒 隱私

- 程式完全在你自己的電腦上執行（網址是 `127.0.0.1`，只有你自己的電腦連得到）。
- 不會上傳你的技能或資料；只有在你選擇雲端 AI 時，你輸入的內容才會送給該 AI 服務。
